# forge / REFERENCES

Described examples of good local-business web design, handed to Forge with
every build.

DESCRIBED, not linked: Forge has no browsing tools, so a URL is useless to it.
Each entry names a technique — a layout, a type pairing, a colour discipline, a
CSS effect — read off a real award-winning site for a business of this kind,
and states what it is FOR.

The real file also carries the caveat that matters: award-winning sites in this
category run to 8,000-24,000 pixels tall with hundreds of images, video and
canvas. Their composition is worth copying and their payload is the opposite of
what a local business's customers can afford, so the sheet says explicitly to
take one and not the other.

It ends by requiring a CHOICE between treatments rather than a blend of them,
because a page that takes a little of each is the one failure mode that
survives every other rule in ROLE.md.
