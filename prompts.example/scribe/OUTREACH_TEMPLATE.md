# scribe/OUTREACH_TEMPLATE

The canonical outreach email: the fixed process facts (what the offer is, what
is included, that it is unsolicited and carries no obligation) plus marked
slots the writer adapts per business.

Keeping this as a template rather than regenerating it each time is what makes
the *process* description constant while the personalisation varies — the parts
a customer could be misled by are the parts that should not be improvised.
